# Sumit Kumar — IT Support Portfolio

A responsive, static portfolio website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive visual design
- `script.js` — mobile navigation and current footer year

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.

No backend, package manager, build tool, or paid hosting is required.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `sumit-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Your public URL will appear in the Pages settings.

## Before publishing
- Check the dates and job details.
- Confirm your LinkedIn URL and phone/email are correct.
- Add a PDF resume link if you want visitors to download your CV.
- The Google Fonts import is optional; the page uses fallback fonts if it cannot load.
